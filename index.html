Прокси с токенами в Cloudflare

  1. dash.cloudflare.com → Workers & Pages → ваш воркер (или Create) → Edit code, вставьте код ниже → Deploy.
  2. Воркер → Settings → Variables and Secrets → Add, тип Secret, три значения:
    WB_TOKEN_EF — токен кабинета EF (категория «Статистика»)
    WB_TOKEN_EZFR — токен кабинета EZFR
    ACCESS_KEY — придумайте пароль. Его один раз вводят на этой странице.
  3. Сохраните (Deploy) и введите тот же пароль в поле «Ключ доступа».

Прокси отвечает только на запросы с ключом и только на чтение статистики продавцов. Если один из кабинетов не нужен, его токен можно не добавлять.
